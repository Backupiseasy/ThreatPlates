# @project-version@ (@build-time@)

* Fixed a Lua error when showing the health text or health-based colors on nameplates on Classic clients, caused by Blizzard now returning unit health as a secret value there as well. On Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), the health text and color now also fade at full health the same way they do on Midnight, instead of just staying visible.
* Fixed Threat Plates wrongly treating some Classic-based clients as retail/Mainline (enabling end-game-only features and expansion logic that didn't apply there), caused by relying solely on an unreliable project-ID check instead of also cross-checking the actual classic expansion level.
* Fixed a Lua error on startup (and a wrong health-text update event) on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by code paths written for the old Classic engine now also running there after the fix above, calling a Blizzard API that was removed from that engine.
* Fixed the healthbar/status text not updating on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by trying to register an old Classic-only event that no longer exists on that engine.
* Fixed a forbidden-action error on login on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by trying to register a combat log event that engine no longer allows addons to register for.
* Fixed a Lua error showing absorb shields on nameplate healthbars on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by the same secret-value restriction as above; such clients now use the same absorb rendering as Midnight instead of the old Classic one.
* Fixed the Quest widget never loading and quest tooltips being misread on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by the widget requiring at least Mists of Pandaria content instead of checking for the actual quest-tooltip API it needs.
* Fixed a Lua error showing auras on nameplates on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by the old (pre-Midnight) Auras widget running there and hitting the same secret-value taint restrictions Midnight itself has; such clients now use the same rebuilt Auras widget as Midnight instead of the old one.
* Fixed a Lua error showing castbars (and a related raid-target-marker error, and a Blizzard nameplate visibility error) on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by several castbar/nameplate code paths written for the old Classic engine that don't handle secret values or frame protection; such clients now use the same castbar timing, raid-marker, and Blizzard-nameplate-visibility handling as Midnight.
* Fixed a Lua error coloring nameplates by raid target marker on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by the raid target marker sometimes being a secret value there as well.
* Hopefully fixed a Lua error showing the castbar interrupt shield/border on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by hiding/showing it in a way that isn't safe with a secret interruptible-state value there.
* Fixed a Lua error re-applying aura appearance settings (e.g. re-opening the options window), caused by an upcoming Blizzard API change (not yet live on retail, but already present on some other client versions) to how a dispel-type border icon is removed and re-added.
* Added support for Classic-rules clients that run on a modern client engine (e.g. "WoW Forever") to the addon's interface declaration, so it no longer needs "Load out of date AddOns" enabled there.
* Added a "/tptp version" chat command that prints the detected WoW client version and expansion.
* Added a "/tptp debug Compatibility" chat command that tries registering every WoW event Threat Plates knows about and reports which ones fail on the current client.
* Added a "/tptp debug MidnightAPI" chat command that checks whether the current client has the Blizzard APIs Threat Plates' Midnight-only code depends on.
* Fixed a Lua error showing the castbar color for a non-interruptible cast on Classic-rules clients that run on a modern client engine (e.g. "WoW Forever"), caused by a plain truthy check on a secret interruptible-state value there.
* Identified (but could not fully resolve) a bug where settings reset on login on some clients, caused by the client not loading saved settings at all in some sessions - most likely needs a fix on the client's own side, not something this addon can work around.
* Updated integrated libraries (Ace3 r1414-alpha).
