# @project-version@ (@build-time@)

* Added options for the nameplate motion speed and the screen insets nameplates are clamped to on WoW Retail and Forever.
* Fixed custom scripts showing a Lua error or a wrong name instead of a warning when using a blocked function or API.
* Reworked how nameplates are added, removed, and anchored to make them more reliable, especially when Blizzard re-uses its internal nameplate frames for different units.
* Fixed a bug where nameplates did not update their style when a unit's classification (e.g., elite or rare) changed.
* Added an option for the size of Blizzard's nameplates to the clickable area settings, as it limits the clickable area of nameplates.
